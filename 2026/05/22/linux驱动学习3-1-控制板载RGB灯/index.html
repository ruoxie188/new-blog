1.2 RGB对应的原理图


💡 点击展开：RK3566 GPIO 编号计算原理

在 Rockchip RK3566（泰山派主控）中，GPIO 编号的计算公式为：

引脚编号 = 控制器编号 * 32 + (组编号 * 8 + 组内偏移)

📐 计算实例：红色灯 (GPIO1_B2)

  1. 确定参数：

    • 控制器编号 = 1 (对应 GPIO1)
    • 组编号 = 1 (对应 A=0, B=1, C=2, D=3)
    • 组内偏移 = 2 (对应 B2 的 2)

  2. 带入公式计算：
    1 * 32 + (1 * 8 + 2) = 42

📐 计算实例：绿色灯 (GPIO1_B1)

  1. 确定参数：

    • 控制器编号 = 1 (对应 GPIO1)
    • 组编号 = 1 (对应 A=0, B=1, C=2, D=3)
    • 组内偏移 = 1 (对应 B1 的 1)

  2. 带入公式计算：
    1 * 32 + (1 * 8 + 1) = 41

📐 计算实例：蓝色灯 (GPIO1_B0)

  1. 确定参数：

    • 控制器编号 = 1 (对应 GPIO1)
    • 组编号 = 1 (对应 A=0, B=1, C=2, D=3)
    • 组内偏移 = 0 (对应 B0 的 0)

  2. 带入公式计算：
    1 * 32 + (1 * 8 + 0) = 40

📌 结论：
我们在驱动中直接操作的 GPIO 编号是 42 41 40。
